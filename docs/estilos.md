# Estilos de EXEX

Bootstrap 5.3.8 se carga mediante enlaces en index.html, siguiendo la forma de carga del ejemplo bloc_app. Conservamos la versión estable 5.3.8 que ya habíamos elegido.

No hace falta instalar Bootstrap con npm. Se necesita conexión a internet para descargar sus estilos y su archivo JavaScript desde el CDN al abrir la aplicación.

Por ahora usamos las clases predeterminadas de Bootstrap:

- Distribución: container, row y col-*.
- Botones: btn btn-primary y btn btn-outline-secondary.
- Formularios: form-label, form-control y form-text.
- Espacios: p-*, m-* y gap-*.

src/index.css solo conserva unas reglas básicas para la pantalla inicial. Las personalizaciones de botones, campos y colores se añadirán cuando las pantallas lo necesiten.
